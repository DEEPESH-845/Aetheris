# Plan: End-to-End Stripe Integration for Aetheris Pricing

## Overview

The codebase already has a solid Stripe foundation (API routes for checkout, portal, webhooks; tRPC billing router; useSubscription hook; PlanBadge, UpgradePrompt components). The main issues are:

1. **Billing page tRPC mutations are stubs** - `createCheckout` and `createPortal` return hardcoded placeholder URLs instead of calling the actual Stripe API
2. **Pricing page links are broken** - Links go to `/sign-up?plan=...` which doesn't exist (no auth pages)
3. **Pricing page has no checkout flow** - Buttons just navigate away instead of triggering Stripe checkout
4. **UPI payment method not supported** - Checkout only allows cards
5. **No Stripe keys configured** - `.env.local` has no Stripe environment variables
6. **Missing Pricing link in site navigation** - SiteHeader doesn't link to `/pricing`

## Changes

### 1. Stripe Account Setup Guide (Documentation)

Create a `.env.example` file and a comment block in `.env.local` listing all required Stripe env vars:

```
STRIPE_SECRET_KEY=sk_test_...
STRIPE_WEBHOOK_SECRET=whsec_...
STRIPE_STARTER_MONTHLY_PRICE_ID=price_...
STRIPE_STARTER_YEARLY_PRICE_ID=price_...
STRIPE_PRO_MONTHLY_PRICE_ID=price_...
STRIPE_PRO_YEARLY_PRICE_ID=price_...
STRIPE_BUSINESS_MONTHLY_PRICE_ID=price_...
STRIPE_BUSINESS_YEARLY_PRICE_ID=price_...
```

Also create a `STRIPE_SETUP.md` guide explaining how to:
1. Create a Stripe account at stripe.com
2. Create Products (Starter, Pro, Business) with Monthly + Yearly prices
3. Copy Price IDs from Stripe Dashboard
4. Create a Webhook endpoint pointing to `your-domain.com/api/stripe/webhooks` with events: `checkout.session.completed`, `customer.subscription.updated`, `customer.subscription.deleted`, `invoice.payment_failed`, `customer.subscription.trial_will_end`
5. Copy Webhook Signing Secret
6. Set all env vars

### 2. Fix Pricing Page Checkout Flow

**File: `src/app/pricing/page.tsx`**

- Remove static `href` links from plan cards
- Add client-side checkout handler that:
  - If user is authenticated: POST to `/api/stripe/checkout` directly, redirect to Stripe Checkout URL
  - If user is NOT authenticated: Open Clerk sign-up modal, then after sign-up, auto-trigger checkout
- For Free plan: link to sign-up (no checkout needed)
- For paid plans: call the Stripe checkout API endpoint directly (not through tRPC)
- Add loading states on buttons during checkout creation
- Handle errors gracefully (show toast or inline error)

### 3. Fix Billing Page (Dashboard)

**File: `src/app/dashboard/admin/billing/page.tsx`**

- Replace `api.billing.createCheckout.useMutation()` with a direct `fetch('/api/stripe/checkout', ...)` call
- Replace `api.billing.createPortal.useMutation()` with a direct `fetch('/api/stripe/portal', ...)` call
- Both should redirect to the returned Stripe URL
- Add loading/error states on buttons

### 4. Fix tRPC Billing Router Stubs

**File: `src/server/routers/billing.ts`**

- `createCheckout` mutation: Actually call the Stripe checkout logic (reuse from the API route) or redirect to the API route
- `createPortal` mutation: Actually call the Stripe portal logic
- Keep the existing `getSubscription` and `getLimits` queries as-is (they work correctly)

### 5. Add UPI + Card Payment Methods

**File: `src/app/api/stripe/checkout/route.ts`**

- Change `payment_method_types: ["card"]` to `payment_method_types: ["card", "upi"]`
- This enables both card and UPI payment options on the Stripe Checkout page

### 6. Add Pricing Link to SiteHeader

**File: `src/components/marketing/SiteHeader.tsx`**

- Add `{ name: 'Pricing', href: '/pricing' }` to the `navLinks` array

### 7. Fix Auth Flow for Pricing Page

**File: `src/app/pricing/page.tsx`**

- Use Clerk's `useAuth` hook to check if user is signed in
- Use Clerk's `useSignUp` or `SignInButton` with modal mode
- For unauthenticated users clicking a paid plan:
  1. Open Clerk sign-up modal
  2. After successful sign-up, create organization + membership (if not exists)
  3. Then trigger Stripe checkout
- For authenticated users: directly trigger checkout

### 8. Ensure Organization Exists After Signup

**File: `src/app/api/stripe/checkout/route.ts`**

- The checkout route already requires membership. But new users won't have one.
- Add logic to create Organization + Membership if the user doesn't have one yet
- This ensures the checkout flow works for brand-new sign-ups
